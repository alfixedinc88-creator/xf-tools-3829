🗄 Our database — moving off the Google Sheet

Each tab of each Google spreadsheet the app uses. 📥 Move copies the tab into our database once and checks it (same rows, same filled cells, same text → ✅); from then on every page reads and saves that tab in our database — the Google Sheet is not used for it any more (it stays as it was, as an old copy). ↩ Back to Google undoes it (anything saved since the move stays only in the database). Best done when nobody is using that screen.

🧪 Test switch

Loading…
ON: a copy of all the app's data is saved. Everything works as usual, so you can try out Transfer, Stock In / Out, Receive, Reorder…
OFF: everything goes back to exactly how it was when the test started. All stock, logs, History, containers, pallets made during the test are erased.
While it's on, every page shows an orange frame and a 🧪 TEST MODE note. Things that can't be erased are blocked: changing Amazon / eBay / Walmart / Shopify listings, prices or quantities, buying or cancelling labels, sending messages, and writing to the Google Sheet.
Not erased: people & passwords, sales and FBA stock that come in from the marketplaces, and the record below.
⚠ Real work done by anyone while test is on is erased too — use it when nobody is doing real stock work or shipping.
