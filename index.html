Connect your Google Sheet. Credentials are stored only in this browser.

1
Go to console.cloud.google.com → your project → APIs & Services → Library → search Google Sheets API → Enable
2
Left menu → IAM & Admin → Service Accounts → Create Service Account → give it any name → skip role steps → Done
3
Click the service account → Keys tab → Add Key → Create new key → JSON → file downloads → open in Notepad → Select All → Copy → paste below
4
Open your Google Sheet → Share → paste the client_email from the JSON → Viewer → Share
5
Copy your Sheet ID from the URL: docs.google.com/spreadsheets/d/SHEET_ID/edit
